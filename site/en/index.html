Keep the Nokia E72's clock right.

NTP Time Sync gets the exact time from NTP servers over Wi-Fi and sets the phone's clock: at boot, then every 6 hours, all on its own. No SIM needed, no mobile data used.

Features

The right time, without thinking about it

A small background service does the syncing. The NTP Time Sync app shows you what it is doing and changes its settings.

Wi-Finever 3G

Wi-Fi only

It uses the Wi-Fi connection that is up, or switches on a Wi-Fi access point you picked, without asking again. It never turns on 3G or GPRS, so the phone needs no SIM.

6 hoursapart

Runs in the background

Starts at boot, syncs about a minute later, then every 6 hours. The interval goes from 15 minutes to 1 week.

×3→39 msround trip

Keeps the best answer

Each sync asks the server 3 times and keeps the answer with the shortest round trip. Replies are checked the way RFC 4330 asks; stray packets and unsynchronized servers are dropped.

-0.391 s→left alone

No needless nudges

Off by less than 0.5 s? It leaves the clock alone (the threshold is a setting). It only sets UTC, so your time zone and daylight saving time stay as they are.

+214 s→0 s

Watches for clock changes

If something else moves the clock, like network operator time or another app, it syncs again 30 s later. At most once per 15 minutes, so it never fights in a loop.

Tiếng Việt/English

An app to go with it

See the status, sync now, change the settings and read the log, right on the phone. Its screens are in Vietnamese or English.

How it works

Three steps, a few seconds

Each sync is just a few small packets over Wi-Fi.

  1. Time to syncAt boot, on schedule, when you choose Sync now, or when something else has just moved the clock.
  2. Find Wi-FiIt uses the Wi-Fi connection that is up, or else switches on a saved access point. No Wi-Fi? It tries again later.
  3. Ask and setIt asks an NTP server 3 times, keeps the best answer, and sets the clock if it is off by more than the threshold.

All settings live in C:\Data\ntpsyncd.ini, which you can also edit by hand with X-plore. The log is C:\Data\ntpsyncd.log; the app shows it under Options › View log.

Install

Put it on your phone

One package, installed like any other Symbian app.

  1. Turn off network operator time if the phone has a SIM: Ctrl. panel › Settings › General › Date and time › Network operator time: Off. Otherwise the network and NTP Time Sync take turns setting the clock.
  2. Download the latest ntp-time-sync-x.y.z.sisx from Releases, with the phone's browser, or on a computer and copy it over.
  3. Install it. Everything goes to phone memory (C:). A few seconds later the phone shows its access point list: pick your Wi-Fi. It syncs right away and remembers that Wi-Fi for next time.
  4. Open NTP Time Sync from Applications to see the status. Choose Sync now, or press the selection key, to sync at any time.

You need

  • A Nokia E72 (S60 3rd Edition Feature Pack 2, Symbian OS 9.3). NTP Time Sync was written and tested on it. Other S60 3rd Edition phones may work but are untested.
  • A hacked phone (InstallServer patch). Setting the system time needs the WriteDeviceData capability, which a self-signed package only gets on a patched phone.
  • Wi-Fi that lets NTP through (UDP port 123). Almost every home network does.

Good to know

  • Updating: if the installer says ntpsyncd is in use, open the app and choose Stop background sync; after installing, choose Start background sync.
  • Uninstalling: choose Stop background sync first. Your settings file, C:\Data\ntpsyncd.ini, is kept.
  • Privacy: it only talks to the NTP servers in its settings. The log stays on the phone (about 128 KB at most) and is never sent anywhere.
  • Can't download on the phone? GitHub only accepts TLS 1.2, and the stock S60 browser only has TLS 1.0. Install the TLS patch, or download on a computer and copy the file over.

Build it yourself

The build runs in a public Docker image with the S60 3rd Edition FP2 SDK, GnuPoc and GCCE, so all you need is a Mac, Linux or Windows (WSL) machine with Docker.

GitHub Actions runs the same build on every push. The files on the Releases page come from it, built from the tagged commit.

# test the NTP maths with your computer's compiler
$ g++ -std=c++98 -Itest/shim -Iinc \
    test/test_ntppacket.cpp src/ntppacket.cpp -o t && ./t

# make the package: sis/ntpsyncd.sisx
$ bash group/docker-build.sh
